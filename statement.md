# Problem Statement

## Project Title
Real-Time Edge Detection using OpenCV

## Scope
This project detects object boundaries in digital images using the Canny Edge Detection algorithm. It provides interactive threshold adjustment and allows users to save processed images.

## Target Users
- Students learning Computer Vision
- Beginners in OpenCV
- Faculty for educational demonstrations

## High-Level Features
- Load an image
- Convert to grayscale
- Detect edges using Canny
- Adjust thresholds interactively
- Save the output image

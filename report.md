# Real-Time Edge Detection using OpenCV

## Submitted By

Name: Anusha

Course: Computer Vision

## Abstract

This project demonstrates the implementation of edge detection using the Canny Edge Detection algorithm in OpenCV. The application loads an image, converts it into grayscale, detects object boundaries, and allows users to adjust threshold values interactively. The processed image can also be saved for future use.

## Objectives

- To understand image preprocessing.
- To implement Canny Edge Detection.
- To detect object boundaries in images.
- To provide interactive threshold adjustment.
- To save the processed output image.

## Software Requirements

- Python 3.10+
- OpenCV
- NumPy
- Visual Studio Code

## Methodology

1. Load the input image.
2. Convert RGB image to grayscale.
3. Apply Canny Edge Detection.
4. Adjust thresholds using sliders.
5. Display original and edge image.
6. Save the output image.

## Results

The application successfully detects edges and allows real-time adjustment of sensitivity. The output image is stored inside the output folder.

## Applications

- Medical image analysis
- Autonomous vehicles
- CCTV surveillance
- Face recognition preprocessing
- Industrial quality inspection

## Conclusion

The project successfully implements a basic computer vision pipeline using OpenCV. It demonstrates preprocessing, edge detection, interactive parameter tuning, and output generation.
